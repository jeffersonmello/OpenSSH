# Identidade visual

## Direção

O OpenSSH Manager usa uma identidade própria para um workspace de infraestrutura: base escura, acentos claros e um símbolo legível em tamanho de ícone. O layout das capturas fornecidas pelo usuário serve apenas como referência de fluxo; dados, credenciais e marcas dessas capturas não devem ser incorporados aos materiais públicos.

## Arquivos

| Arquivo | Uso |
| --- | --- |
| `assets/brand/logo.png` | Logo principal e origem do ícone macOS |
| `assets/brand/banner.png` | Capa do README e apresentação do projeto |
| `docs/images/app-preview.png` | Captura real da interface em demonstração |

Logo e banner são raster gerados pela ferramenta nativa `image_gen`, em modo built-in. Os [prompts finais e o registro de inspeção](../assets/brand/prompts.md) estão versionados com os assets. O logo tem 1254 × 1254 px e o banner 2098 × 749 px. A screenshot de 1440 × 920 px é uma captura real do aplicativo em modo demo, não uma imagem gerada.

## Uso e transparência

- Não representar a interface de uma imagem promocional como funcionalidade já entregue.
- Manter contraste e margem em torno do símbolo.
- Não reutilizar marca, logo ou screenshot do Termius como identidade do produto.
- Não usar screenshots que exponham endereços reais, usuários, senhas ou chaves.
- A licença MIT do repositório se aplica aos materiais incluídos, na medida dos direitos disponíveis. Conteúdo gerado por IA pode ter proteção autoral diferente conforme a jurisdição.
