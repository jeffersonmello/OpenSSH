# Prompts de identidade visual

Gerados em 18/11/2026 com a ferramenta nativa `image_gen`, modo built-in. Os arquivos finais foram copiados para este repositório. Sem imagens de referência ou dados das capturas do usuário.

## Logo — `logo.png`

```text
Use case: logo-brand
Asset type: open source desktop app logo, standalone square PNG.
Primary request: Create an original polished app icon for "OpenSSH Manager", a fast Rust desktop workspace for SSH connections, key management, SOCKS tunnels and file transfer. The brand should communicate an open connection and an elegant terminal prompt. One unified simple geometric symbol using two interlocking angular brackets and a subtle connecting path, legible at tiny sizes, crafted silhouette.
Scene/backdrop: square dark ink background #0D141C with subtly rounded icon tile.
Style/medium: precise vector-like flat graphic with restrained depth, premium developer tool.
Color palette: warm ivory and vivid mint #64E4BD on dark ink. No neon glow.
Composition: symbol centered with generous padding, full square icon, no mockup.
Text: no text, no lettering.
Constraints: wholly original, no Termius or OpenBSD logo, no pufferfish, no copied trademark, no private keys, no watermark.
```

## Banner — `banner.png`

```text
Use case: logo-brand
Asset type: wide GitHub README banner for an open source native Rust macOS desktop app. Landscape aspect ratio approximately 2.8:1.
Primary request: Design an original premium developer-tool brand banner for "OpenSSH Manager", a workspace for SSH connections, keys, SOCKS tunnels and file transfers.
Scene/backdrop: very dark ink #0E141C with a subtle technical grid and fine routing lines in the background. Crisp editorial composition with comfortable negative space.
Subject: an original geometric linked angular-bracket terminal symbol in warm ivory and mint #64E4BD, consistent with a bracket linkage and >_ prompt. A few understated connection nodes on the right suggest infrastructure routing. No screenshot or fake UI.
Typography: beautifully set strong modern sans serif. Name on the left, restrained small supporting line below, small open source label. Text exactly and legibly:
"OpenSSH"
"Your infrastructure. Connected."
"RUST · macOS · OPEN SOURCE"
Style: calm and precise, flat graphic with minimal restrained depth, dark developer workspace identity, no excessive glow.
Constraints: No Termius branding, no OpenBSD pufferfish, no borrowed logos, no private keys or real addresses, no watermark. Wide full-bleed composition.
```

Inspeção visual: nome e textos do banner corretos, paleta escura com menta e marfim, símbolo original de conexão e terminal. Sem dados reais ou marcas das capturas fornecidas. A screenshot em `docs/images/app-preview.png` é produzida pelo aplicativo em modo demo, não pelo gerador.
