# Especificações

Cada mudança de comportamento liga requisitos, decisão de implementação e validação. A especificação inicial é [001-native-workspace](001-native-workspace/spec.md).

Use [templates/feature.md](templates/feature.md) para uma nova demanda. Os arquivos têm papéis distintos:

- `spec.md`: problema, escopo, requisitos e critérios de aceite.
- `plan.md`: arquitetura e decisões de implementação.
- `tasks.md`: trabalho e evidências, com limites conhecidos.

Uma correção pequena pode atualizar a spec existente. O status precisa refletir evidências reais: implementado não significa validado em toda a matriz de servidores.
